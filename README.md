# 🏍️ Bike Racing Game

A 2D Bike Racing Game developed using **Python and Pygame**. Dodge traffic, avoid obstacles, activate nitro boosts, and try to beat your highest score!

## 🎮 Features

- Multiple selectable bikes
- Three backgrounds: Classic, Desert, and Snow
- Three difficulty levels: Easy, Medium, and Hard
- Nitro boost system
- Moving enemy bikes
- Obstacles including cones, barriers, and oil spills
- Score and high-score tracking
- Speedometer
- Background music and sound effects
- Pause, resume, and restart options

## 🛠️ Technologies Used

- Python 3.12
- Pygame
- PyInstaller / auto-py-to-exe (for creating a Windows executable)

## ⚙️ Installation

1. Install Python 3.12.
2. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

3. Open the project folder:

```bash
cd Bike_Racing_Game
```

4. Install Pygame:

```bash
py -3.12 -m pip install pygame
```

5. Run the game:

```bash
py -3.12 main.py
```

## 🎯 Game Controls

| Key | Action |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |
| SPACE | Nitro Boost |
| P | Pause / Resume |
| R | Restart after Game Over |
| M | Return to Main Menu |
| Q | Quit |
| ENTER | Start Game |
